# Smart Finance Tracker

**Smart Finance Tracker** is a Python-based application that enables users to manage, analyze, and visualize their personal finances efficiently. This project facilitates budgeting, expense recording, and financial report generation, streamlining financial planning for individuals.

## Features

- **Expense Tracking**: Log daily expenses and categorize spending.
- **Budget Setting**: Set monthly or custom budgets and monitor your spending against set limits.
- **Financial Analysis**: Generate analytical reports to visualize increase/decrease in spending trends.
- **Export Reports**: Save financial reports (e.g., as PDF or CSV files) for archiving and sharing.
- **Test Cases**: Validate application logic through included automated tests.

## Getting Started

### Prerequisites

- Python 3.x
- All dependencies listed in `requirements.txt`

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Shivmahlan/Smart-Finance-Tracker.git
   cd Smart-Finance-Tracker
   ```

2. Install required packages:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the main application:
   ```bash
   python app.py
   ```

## Repository Structure

- `app.py`: Main application file.
- `finanace.py`: Core financial logic and operations.
- `budget.txt`: Stores user-defined budget data.
- `expenses.csv`: Expense data storage.
- `Expense_Report_September_2025.pdf`: Sample exported report.
- `testcase44.py`: Automated test scenarios.
- `requirements.txt`: List of required Python packages.

## Usage Example

1. Set your budget in `budget.txt`.
2. Add or modify expense entries in `expenses.csv`.
3. Run the application to analyze your finances and generate reports.
4. Consult the PDF or CSV reports for detailed breakdowns.
